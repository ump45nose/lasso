# Lasso 0.8.5：迁移与续做清单

2026-11-06。依据 `main`（`7614b0c`）的源码、提交和 `docs/plans/` 核对。版本号自 `7b01900`（10-31）未再升，11-04 之后合入的截图套件、常驻工具和重构也报 0.8.5。

## 已确定的产品方向

个人自用，解决开发时切去网页处理查询、文本处理、个人信息总结等轻任务的中断。正式开发继续在 Codex；本工具复用网站与 CLI，不另建执行引擎。2026-11-05 的 [系统工具集计划](plans/system-suite-and-nook-bridge.md) 把范围扩展为常驻 macOS 交互壳，收编便签、Finder 动作和窗口分屏并与 Nook 联动；截图贴图同期按 PixPin 式套件扩展（`5b832df`）。

- 选区附近出现只含预设的动作条，执行后小窗也跟随选区避让定位。目标放在预设设置或入口二级菜单。目标为 API 的文本预设不开小窗，在动作条旁展开流式结果卡片。
- 「问 AI」是普通预设，可配置先编辑或直接发送。网页先编辑直接进入网页输入框，不加本地文字中转层；长文本完整插入，不塞 URL、不截断。
- 默认新对话；旧任务后台继续。一个小窗、顶部标签优先，溢出显示 +N（进入 ⌘K 任务列表）；多窗口留后续。退出不恢复任务列表，不保存完整聊天副本。
- 应用专属提示词按 bundle ID，只对本次明确划词来源注入一次：“应用背景 → 预设展开内容”。无选区、剪贴板图片、截图及其 OCR 文字和后续追问均不注入。网站级匹配留后续。
- 对话目标为 ChatGPT / Gemini / Codex / Pi。CLI 以自定义图形聊天呈现，默认沿用用户配置和主目录，新任务可临时选目录；不绕过审批或项目信任机制。API 只是预设里显式选择的目标（文本卡片、Images API 生图），不从网页静默切换。
- AI 任务首批单图，不做多图。失败保留图片及待提交内容，不自动降级为 OCR、丢图发送或重复提交。
- 视觉以 [界面规则](design/ui-rules.md) 和 `docs/design/v2/` 为准（象牙底、陶土 `#D97757`、衬线体）；[最初原型](design/index.html) 只作历史参考。
- 可配置的全局动作默认不绑定，不使用 Raycast 的 Option+Space。例外：常驻套件启动即固定注册 ⌃⌥←/→/↑/↓/↵/N/F（分屏键位按计划沿用 Rectangle），设置里不能改或关闭，被占用时静默跳过。
- 软件优先复用免费、成熟的开源能力。完整截图必须包含内部区域自动识别与图片上直接拖选局部文字；只输出 OCR 文本面板不满足要求。
- 闲置休眠默认 30 分钟（1—1440 分钟或关闭），网页任务、待命页、CLI 进程和截图编辑器共用，取代固定 10 分钟（`7b01900`）。截图历史默认开启（50 条 / 30 天 / 512 MB）、贴图默认启动时恢复，与截图方案 S4 第 5 条（默认不持久化历史、贴图只保留本次运行）不同。

## 下一步先做什么

### P0：打包版验收

1. **ChatGPT 菜单反复开关**：运行已有模型＋深度预设，观察配置、填入和发送前核对的整个流程。应不在轮询中反复点击；已匹配时不展开；外部改变配置应拦住发送。冷启动的档位发现应留在隐藏页。若仍闪动，记录原生菜单的实际状态转换，修正 `web-profile.ts`，不要重新引入可见遍历。
2. **截图**：按 [截图方案第 7 节](screenshot-implementation-plan.md#7-集中验收清单) 逐项检查，补负坐标、混合缩放、热插拔和拒绝屏幕录制权限，S1 结论在新实现上重测；按 [编辑器性能与贴图](plans/editor-performance-and-pin.md) 手测拖动跟手、剪贴板、⌘W 和贴图内编辑。
3. **常驻套件**：按 [系统工具集计划](plans/system-suite-and-nook-bridge.md) 第一、二批的验收标准检查。⌃⌥ 键若已被 Rectangle 等占用，注册失败不会提示（代码静默忽略）。
4. **录屏、滚动截图、生图、WebDAV、历史与贴图工作区**：没有计划文档，按 AGENTS.md 在打包版手测。

### P1：补完原路径集中验收

- 四应用划词；长文本；先编辑不发送、直接发送不重复；应用背景不误注入；真实选区下动作条边距的鼠标穿透。
- 两网站单图及上传失败重试；ChatGPT 真实完成→后台闲置→释放→原链接恢复，不重复提交。
- CLI 的模型/强度、工作目录、工具进度、停止、审批及连续对话；切换标签不串内容。Pi 图片沿用上表的验收决定。
- Finder 启动、关闭/退出与资源释放；仅结束本应用启动的 CLI 和工具，不影响 Codex Desktop。
- 焦点在网页内的 ⌘K、导入字体后重启、减少动态效果、启动及唤起延迟；不要只凭存在 CSS transition 判定体验完成。

### P2：计划内未实现的范围

- 系统工具集计划中代码未见的部分，见该计划状态行。
- Claude 网页、网站级提示词、多窗口、语音、Live2D、论坛入口和更多 bot 仍是后续路线。

## 新 Mac 迁移步骤

### 1. 克隆并构建

```sh
gh repo clone ump45nose/lasso
cd lasso
npm ci
npm run signing:setup
npm run package
open release/Lasso-darwin-$(node -p process.arch)
```

- 先安装 Node.js 22.12+ 与 Xcode Command Line Tools（`xcode-select --install`），系统需 macOS 14.2+。`npm ci` 使用锁文件恢复依赖；不要复制旧机的 `node_modules` 或已编译 `.node`。
- `scripts/build-capture.mjs` 根据当前 Node 安装前缀查找头文件，再查 Homebrew；自定义环境可用 `NODE_INCLUDE_DIR=/path/to/include/node npm run package`。不自动下载或替换系统工具。
- 构建按本机架构。本机验收过的只有 arm64。
- 签名私钥只在本机钥匙串，现有脚本创建不可导出的本机开发身份。新 Mac 首次创建自己的证书；同名证书不代表旧身份，不复制旧机授权记录。后续本机更新继续复用该证书，缺失就停止打包，不降级 ad-hoc。`npm run package -- --release` 是 CI 用的临时签名。

### 2. 安装与账号

将 `.app` 放到 `~/Applications/Lasso.app`，从 Finder 启动。首次授权辅助功能（划词、分屏和快速卡片替换原文都依赖它），在设置 → 通用确认划词状态，再实际拖选一段文字；开关亮起不能替代实际划词验证。截图和录屏另需屏幕录制授权，录屏的麦克风、摄像头按需授权，并在解锁桌面测试。

ChatGPT / Gemini 分别在小窗登录。Codex / Pi 先在新 Mac 安装并完成自己的登录，在 Lasso 设置中选 **绝对路径** 和工作目录；默认主目录。GUI 不依赖启动终端的 PATH。用户级 MCP、Skills、扩展由 CLI 自己管理，不在本仓库。生图和智能识别服务的 Key 在新机重新填写。

### 3. 只迁移需要的本地配置

数据目录固定为 `~/Library/Application Support/mac-ai-prompt/`。先退出两端 Lasso：

- 配置包：设置 → 通用 →「同步与迁移」导出后在新机导入，或两端启用同一 WebDAV。包内只有白名单内的偏好、快捷键和预设，不含凭据、CLI 路径、保存目录和导入字体。
- `presets.json` / `settings.json`：也可私下复制。`settings.json` 含应用背景、CLI 绝对路径和目录；复制前保留新机器原文件，复制后在界面重新选择本机 CLI 路径、目录并检查快捷键冲突。
- `capture-history/`、`pins-workspace/`、`generated-media/` 的结果和 `~/Documents/LassoNotes` 是个人内容，按需私下复制；跨机读取未验证。
- **不迁移到 Git**：网站登录分区/Cookies、本机钥匙串、CLI 账号凭据及会话、签名密钥、safeStorage 加密的服务凭据与 WebDAV 密码（依赖本机钥匙串，推断换机需重填）、`input-images/`、`recording-sessions/`、临时探针和运行日志。网站在新机重新登录；CLI 数据按其官方方式私下迁移。
- 本应用不保存完整聊天副本，也不在重启后恢复任务列表；网站和 CLI 保持各自的会话记录。

保持 bundle ID `local.mac-ai-prompt`、userData 路径和可配置动作默认不绑定；更新安装前保留旧 `.app`，不要删除用户数据。迁移完成并实际验证前，不清理旧 Mac 的应用/配置。
