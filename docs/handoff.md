# Lasso 0.3.0：迁移与续做清单

2026-10-23。源代码交接基线，保留当前安装版的产品方向。先复核下列待验收路径，再扩展截图 S2；不要把历史通过的构建、协议或原型结果当作本机真实界面验收。

## 已确定的产品方向

个人自用，解决开发时切去网页处理查询、文本处理、个人信息总结等轻任务的中断。正式开发继续在 Codex；本工具复用网站与 CLI，不另建执行引擎。

- 选区附近出现只含预设的动作条，执行后小窗也跟随选区避让定位。目标放在预设设置或入口二级菜单。
- 「问 AI」是普通预设，可配置先编辑或直接发送。网页先编辑直接进入网页输入框，不加本地文字中转层；长文本完整插入，不塞 URL、不截断。
- 默认新对话；旧任务后台继续。一个小窗、顶部标签优先、溢出下拉；多窗口留后续。退出不恢复任务列表，不保存完整聊天副本。
- 应用专属提示词按 bundle ID，只对本次明确划词来源注入一次：“应用背景 → 预设展开内容”。无选区、剪贴板图片、截图和后续追问均不注入。网站级匹配留后续。
- 四个目标为 ChatGPT / Gemini / Codex / Pi。CLI 以自定义图形聊天呈现，默认沿用用户配置和主目录，新任务可临时选目录；不绕过审批或项目信任机制。
- 首批单图，不做多图。失败保留图片及待提交内容，不自动降级为 OCR、丢图发送或重复提交。
- 暖白、柔橙、衬线体，参考 [已确认原型](design/index.html)。默认无全局快捷键，不使用 Raycast 的 Option+Space。
- 软件优先复用免费、成熟的开源能力。完整截图必须包含内部区域自动识别与图片上直接拖选局部文字；只输出 OCR 文本面板不满足要求。

## 下一步先做什么

### P0：先在解锁的新 Mac 复核两个未闭环路径

1. **ChatGPT 菜单反复开关**：运行已有模型＋深度预设，观察配置、填入和发送前核对的整个流程。应不在轮询中反复点击；已匹配时不展开；外部改变配置应拦住发送。冷启动的档位发现应留在隐藏页。若仍闪动，记录原生菜单的实际状态转换，修正 `web-profile.ts`，不要重新引入可见遍历。
2. **截图 S1 真实取图与候选**：Chrome 帖子、微信消息、钉钉消息各选非敏感样例；确认存在合理内部区域候选，而非只有整窗。核对微调、原像素裁剪、复制后实际粘贴、保存。测试 Retina/外接屏/负坐标与拒绝权限。此项通过前不宣称自动区域识别已完成。

### P1：补完原路径集中验收

- 四应用划词；长文本；先编辑不发送、直接发送不重复；应用背景不误注入。
- 两网站单图及上传失败重试；ChatGPT 真实完成→后台闲置→释放→原链接恢复，不重复提交。
- CLI 的模型/强度、工作目录、工具进度、停止、审批及连续对话；切换标签不串内容。Pi 图片沿用上表的验收决定。
- Finder 启动、关闭/退出与资源释放；仅结束本应用启动的 CLI 和工具，不影响 Codex Desktop。
- 启动及唤起延迟、窗口/标签/设置动效实际观感。保留“减少动态效果”，不要只凭存在 CSS transition 判定体验完成。

### P2：截图 S2 → S3 → S4

S1 验收后，按 [截图实施方案](screenshot-implementation-plan.md) 继续：成熟标注组件、Vision 文字覆盖层、遮挡后的文字失效与统一导出、贴图及旧剪贴板入口互通。eSearch GPL 代码若被提取，先处理许可；当前 S1 未复制其标注代码。

## 架构与资源所有权

| 位置 | 责任 |
| --- | --- |
| `src/main/index.ts` | 窗口、托盘、菜单、权限入口、安全与窄 IPC；协调显示，不持有另一套任务状态。 |
| `src/main/tasks.ts` | TaskManager 唯一管理任务、待命页、标签投影、网页/CLI 资源、待提交输入、回收及恢复。 |
| `src/main/adapters/` | 网站选择器、完整填入、附件、单次发送、模型/深度选择与状态识别。网站变化在这里修。 |
| `src/main/agents/` | Codex 共享 app-server 和独立 thread；Pi 每任务一个 RPC 进程；原生审批/交互与会话恢复。 |
| `src/main/images.ts` | 原图、临时文件与缩略图；任务持有自己的待处理引用。 |
| `src/main/selection.ts` / `action-bar.ts` | selection-hook 生命周期、冻结选区及来源、就近动作条。 |
| `src/main/capture/` / `native/capture-ax.mm` | 独立截图会话；窗口/AX 只取矩形；边缘/颜色计算在 worker。取消释放图片与 worker，不处理 AI 任务。 |
| `src/renderer/` / `src/preload/` | 暖色衬线界面、Markdown/工具进度、增量消息；本地 frame 限定的 IPC。远程网站没有 Node 或本地 preload。 |

网页后台闲置 10 分钟，完成、无草稿/附件/待确认且可恢复才回收；释放前用临时隐藏页核对历史与最新回答。失败保留原页。Pi 用 session 文件，Codex 用 thread 恢复原目录；恢复不重发。生成中、等待审批、草稿与未知状态均保留。退出不持久化本次任务列表。

## 新 Mac 迁移步骤

### 1. 克隆并构建

```sh
gh repo clone ump45nose/lasso
cd lasso
npm ci
npm run signing:setup
npm run package
open release/Lasso-darwin-$(node -p process.arch)
```

- 先安装 Node.js 22.12+ 与 Xcode Command Line Tools（`xcode-select --install`）。`npm ci` 使用锁文件恢复依赖；不要复制旧机的 `node_modules` 或已编译 `.node`。
- `scripts/build-capture.mjs` 根据当前 Node 安装前缀查找头文件，再查 Homebrew；自定义环境可用 `NODE_INCLUDE_DIR=/path/to/include/node npm run package`。不自动下载或替换系统工具。
- 构建按本机架构。已有验收为 arm64；Intel 构建及原生依赖未验证。
- 签名私钥只在本机钥匙串，现有脚本创建不可导出的本机开发身份。新 Mac 首次创建自己的证书；同名证书不代表旧身份，不复制旧机授权记录。后续本机更新继续复用该证书，缺失就停止打包，不降级 ad-hoc。

### 2. 安装与账号

将 `.app` 放到 `~/Applications/Lasso.app`，从 Finder 启动。首次授权辅助功能，在设置 → 通用确认划词状态，再实际拖选一段文字；开关亮起不能替代实际划词验证。截图另需屏幕录制授权，并在解锁桌面测试。

ChatGPT / Gemini 分别在小窗登录。Codex / Pi 先在新 Mac 安装并完成自己的登录，在 Lasso 设置中选 **绝对路径** 和工作目录；默认主目录。GUI 不依赖启动终端的 PATH。用户级 MCP、Skills、扩展由 CLI 自己管理，不在本仓库。

### 3. 只迁移需要的本地配置

数据目录固定为 `~/Library/Application Support/mac-ai-prompt/`。退出两端 Lasso 后，通过 AirDrop 等私下传递需要的文件：

- `presets.json`：可迁移，保留自定义预设；其中可能有个人提示词，不进入仓库。
- `settings.json`：可选迁移，含应用背景、CLI 绝对路径和目录。复制前保留新机器原文件，复制后必须在界面重新选择本机 CLI 路径、目录并检查快捷键冲突；不想带旧路径就只迁移预设，在设置里重建应用背景。
- **不迁移到 Git**：网站登录分区/Cookies、本机钥匙串、CLI 账号凭据及会话、签名密钥、`input-images/`、临时探针和运行日志。网站在新机重新登录；CLI 数据按其官方方式私下迁移。
- 本应用不保存完整聊天副本，也不在重启后恢复任务列表；网站和 CLI 保持各自的会话记录。

保持 bundle ID `local.mac-ai-prompt`、userData 路径和默认无快捷键；更新安装前保留旧 `.app`，不要删除用户数据。迁移完成并实际验证前，不清理旧 Mac 的应用/配置。
