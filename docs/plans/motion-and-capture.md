# 动效、动作条、原地截图编辑与贴图

## 范围
1. 动效：引入 motion（motion.dev，MIT）。主窗口用它做退出动画、滑动指示块和弹簧按压；悬停、按压、颜色过渡仍用 CSS。
2. 划词动作条：窗口改透明，胶囊和阴影由 CSS 绘制，透明边距设为鼠标穿透；补上悬停滑块、提示卡、进入动画和投递变形。
3. 截图编辑器：屏幕截图原地编辑（冻结屏幕上直接标注，浮动工具条）；剪贴板图片和贴图用窗口布局，复用同一组件。
4. 贴图：图片铺满窗口，悬停时浮出墨色工具条，聚焦时显示柔橙描边。
5. 去掉关闭任务、重新加载任务和退出 Lasso 的确认框。麦克风/摄像头授权的确认保留。

## 关键决定
- 动作条用透明窗口加 `setIgnoreMouseEvents(true, { forward: true })`。只有指针在胶囊上时才接收点击；`contains()` 判断胶囊矩形，不判断整窗。
- 动作条的「更多」继续用系统菜单。
- 编辑器的引擎、OCR、导出和快捷键逻辑不动，只重做布局和样式。
- 交互统一用陶土色回应（用户 2026-10-25 反馈主题色用得少）：悬停、选中改用 `--clay-wash` / `--clay-wash-2` / `--clay-line`，主按钮悬停变陶土色，当前标签底部加陶土线；动作条悬停块用实色陶土，按下再加深。截图编辑器和贴图沿用同一规则。

## 验收
- 关闭、重新加载、退出都不弹确认。
- 动作条：悬停滑块、延迟提示卡、按压、投递变形都可见；透明边距可以点到背后的应用。
- 编辑器两种布局下工具、样式面板、OCR 浮条、裁剪、取色都可用。
- 贴图静止时只显示图片，悬停出现工具条。
- 减少动态时，以上动画全部退化为直接显隐。

## 验证记录（2026-10-25）
在 dist 副本中用独立 userData 启动，通过主进程 inspector 取帧和截图。

实测通过：
- 主窗口：标签切换时背景块滑动（逐帧坐标 160→8 连续变化）；设置分类下划线滑动；⌘K 面板退出时透明度逐渐降到 0 后才卸载。
- 动作条：直接显示窗口并发送 `bar:enter`。悬停块在按钮间滑动，提示卡延迟出现后跟随移动；按下变深陶土，随后显示「正在交给 ChatGPT…」和进度线。
- 编辑器：用测试窗口加载真实组件，替换掉 preload 并伪造 OCR。原地布局中，舞台与冻结屏幕严格对齐，还检查了尺寸标签、OCR 浮条、工具条居中、样式面板和格式菜单。窗口布局检查了书桌底色、缩放、OCR 弹层和单行工具条。
- 贴图：同样用替换 preload 的方式实测，静止时显示陶土聚焦描边，悬停时出现墨色工具条和状态条。

## 第二轮（2026-10-25）：截图模式、原地编辑定位、自绘菜单、官方图标、外包风格约束

### 范围与决定
- **原地编辑铺满全屏的问题**：原因是 `select()` 把编辑图换成选区图之后，渲染端仍拿它当全屏背景。
  - 修法：state 新增 `backdrop`（冻结屏幕，只用于显示）和 `placement`（选区在屏幕上的位置）。编辑器按 `placement` 摆放，缩放比例为 `placement.width / 像素宽`。
  - 导出和 OCR 仍然只用截取到的像素。
- **截图模式**：`area` / `window` / `screen` / `front`。
  - 每种模式都有独立快捷键（`captureShortcuts`，旧的 `screenshotShortcut` 自动迁移到 `area`），托盘里有「区域截图」和「更多截图方式」，⌘K 面板里四种都有。
  - 覆盖层底部改为陶土色模式切换条，空格在区域和窗口之间切换，F 为全屏。
  - 窗口截图用 `screencapture -l<CGWindowID>`，被遮挡的部分也是完整的。默认不带阴影，以便原地对齐；按住 ⌥ 点击会带上阴影，阴影边距按图像 alpha 实测后加进 `placement`。原生 `windows()` 新增 `id` 字段。
- **动作条 ···**：不再用 NSMenu，改为窗口内的墨色菜单（列出剩余预设和「预设设置…」）。
  - 主进程在显示时决定菜单开在哪一侧（`ActionBarLayout`），打开时窗口在这一侧变高，胶囊锚定在另一侧，所以位置不会跳。
  - 菜单打开期间，`contains()` 按整个窗口判断命中。
- **贴图 ···**：同样不再用原生菜单，改为第二行墨色工具条（置顶、透明度循环切换、缩放、穿透、隐藏），主进程对应拆成独立的贴图动作。
- **渠道图标**：ChatGPT、Codex 取自本机 ChatGPT.app 的资源，Gemini 取自本机 Gemini.app，Pi 取自 pi.dev 官方 SVG（经用户同意下载）。统一放在 `src/renderer/assets/targets/`，由 `targetIcons` 的 Record 类型强制每个渠道都有图标。
- **外包风格约束**：`AGENTS.md`、`docs/design/ui-rules.md`、`scripts/check-ui.mjs`（已接入 build）、`npm run ui:shots`（`scripts/ui-shots/`，配合 `LASSO_PROFILE` 使用独立配置）。
  - 零散颜色已收为令牌：`--clay-press` `--stage` `--ink-6` `--track`。
  - 截图编辑器的 `window.confirm` 改为原地二次确认。

### 验证（第二轮）

- 原地编辑器：选区图与冻结屏幕严格对齐，跨边界的文字连续；工具条和 OCR 浮条位置正确。
