# 前端视觉与交互重构

2026-10-25 启动。范围、决定与进度在此维护；恢复任务先读本文件。

## 已确认需求

- 风格：Anthropic 产品与品牌融合。日常界面克制、好用；空状态、动作条、截图引导借用编辑排版感（大衬线标题、留白、手绘线条点缀）。原创设计，不复制 Claude / Anthropic 的界面与标志。
- 范围：全部界面——主小窗外壳、划词动作条、CLI 聊天、图片入口、设置、截图覆盖层。
- 幅度：重新构想交互与信息结构，可牵动主进程与 IPC；产品规则不变（见 [handoff](../handoff.md#已确定的产品方向)，尤其「网页先编辑不加本地文字中转层」「默认无全局快捷键」「失败保留内容」）。
- 主题：第一版只做浅色。
- 字体：模拟 Anthropic Serif / Sans 观感，使用开源字体随应用打包（Newsreader、Instrument Sans、思源宋体子集、JetBrains Mono）；中文界面正文用系统苹方。
- 标志：设计完成后评估现有 Logo 与图标是否契合，再决定是否调整。
- 交付：先概览设计稿确认方向，再出详细设计（HTML 交互原型，存入 `docs/design/`）。

## 概览设计稿（待确认）

画布：<https://claude.ai/artifact/W7a9JZxok91JKEhiFUDj2U>（私有，10 张画板）。方向名「纸上的套索」：

- 色彩：Ivory `#FAF9F5` 底、Paper `#FFFFFF` 卡片、Slate `#141413` 墨色、暖灰阶；Clay `#D97757` 只用于选区、进行中与每屏唯一主操作，强调文字用 Clay Ink `#A4502F`。
- 字体：展示与 AI 回答用衬线（Newsreader / 思源宋体），界面用 Instrument Sans / 苹方，数据与代码用 JetBrains Mono。
- 笔迹：荧光笔一笔高亮（选区）、手绘套索圈（启动台），与现有标志同源。
- 结构：头部 80px → 44px 单行（任务、新建、置顶、⌘K）；3 个原生菜单合并为 ⌘K 指令面板（⇥ 临时换目标）；投递状态改为底部步骤进度；错误统一到同一提示位；动作条改石板深色；预设设置按「动作条前 4 个 / 更多菜单」分组；待处理图片以临时标签出现。
- 技术牵动：主进程 `HEADER_HEIGHT` 与投递条位置；指令面板需独立浮层窗口（原生网页视图在 React 之上）；ShellState 的错误字段合并；动作条交付中状态需改为执行后短暂保留。
