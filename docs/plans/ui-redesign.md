# 前端视觉与交互重构

2026-10-25 启动。范围、决定与进度在此维护；恢复任务先读本文件。

## 已确认需求

- 风格：Anthropic 产品与品牌融合。日常界面克制、好用；空状态、动作条、截图引导借用编辑排版感（大衬线标题、留白、手绘线条点缀）。原创设计，不复制 Claude / Anthropic 的界面与标志。
- 范围：全部界面——主小窗外壳、划词动作条、CLI 聊天、图片入口、设置、截图覆盖层。
- 幅度：重新构想交互与信息结构，可牵动主进程与 IPC；产品规则不变（见 [handoff](../handoff.md#已确定的产品方向)，尤其「网页先编辑不加本地文字中转层」「默认无全局快捷键」「失败保留内容」）。
- 主题：第一版只做浅色。
- 字体（2026-10-25 更新）：标题、回答正文、界面文字默认全部用衬线 Anthropic Serif Text（本机已安装，仅 Light 一个字重，含中文）；代码与数据用 JetBrains Mono。只打包 Newsreader 与 JetBrains Mono 作后备，中文后备用系统宋体，不打包中文字体。设置 → 外观 可按四个角色更换本机字体或导入字体文件。
- 标志：设计完成后评估现有 Logo 与图标是否契合，再决定是否调整。
- 交付：先概览设计稿确认方向，再出详细设计（HTML 交互原型，存入 `docs/design/`）。

## 概览设计稿（已确认）

画布：<https://claude.ai/artifact/W7a9JZxok91JKEhiFUDj2U>（私有，10 张画板）。方向名「纸上的套索」：

- 色彩：Ivory `#FAF9F5` 底、Paper `#FFFFFF` 卡片、Slate `#141413` 墨色、暖灰阶；Clay `#D97757` 只用于选区、进行中与每屏唯一主操作，强调文字用 Clay Ink `#A4502F`。
- 字体：概览阶段用开源字体模拟；详细设计改为默认全部衬线（见上方字体决定）。
- 笔迹：荧光笔一笔高亮（选区）、手绘套索圈（启动台），与现有标志同源。
- 结构：头部 80px → 44px 单行（任务、新建、置顶、⌘K）；3 个原生菜单合并为 ⌘K 指令面板（⇥ 临时换目标）；投递状态改为底部步骤进度；错误统一到同一提示位；动作条改石板深色；预设设置按「动作条前 4 个 / 更多菜单」分组；待处理图片以临时标签出现。
- 技术牵动：主进程 `HEADER_HEIGHT` 与投递条位置；ShellState 的错误字段合并；动作条交付中状态需改为执行后短暂保留。指令面板见下方详细设计决定。

## 详细设计

原型与规范：<https://claude.ai/artifact/MQyv354emqN3CfkEjXyosy>（私有）；源文件 `docs/design/v2/`（`index.html`、`lasso.css` 变量与组件、`app.js` 原型）。本地预览需要静态服务器，例如在该目录运行 `python3 -m http.server`。

关键决定：

- 标题栏 44px：任务标签最多 3 个，溢出 +N；目标徽标只在当前标签显示。网页视图下方按提示行数让出高度（每行 48px），投递进度与应用级提示共用这一位置。
- 指令面板替代运行预设、新对话、更多任务三个系统菜单（托盘菜单保留）。打开时隐藏网页视图，用 `capturePage` 截图作背景，不另开浮层窗口。⇥ / ⇧⇥ 为选中的预设临时换目标，换目标后模型与强度跟随目标默认。
- 投递步骤按预设生成：打开 →（模型）→（图片）→ 填入 → 发送 / 交给你；失败从失败步骤重试，不重复已完成步骤。
- `ShellState` 增加 `notice` 合并截图与剪贴板图片错误；投递状态增加 `steps`。
- 字体配置：`settings.fonts`（display / text / ui / mono 四个字体族名）与 `importedFonts`（family、文件名）。导入文件复制到 `userData/fonts/`，经 `lasso-font://` 协议提供，CSP 增加 `font-src`，本地窗口允许 `local-fonts` 权限以列出本机字体；字体缺失时标出并使用后备。只作用于 Lasso 本地界面。
- 标志：现有标记（荧光笔一笔 + 线条 + 光芒）与「纸上的套索」同源，应用图标的深色底 + Clay + Ivory 也一致，保留不改。实现时把 `assets/lasso-mark.svg` 的 `#C57556` / `#292823` 对齐为 `#D97757` / `#141413`。
