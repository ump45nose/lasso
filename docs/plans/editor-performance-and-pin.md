# 截图编辑性能与贴图行为

## 范围

截图进入编辑后，箭头到高亮、遮挡、马赛克、模糊、取色和复制发沉。贴图默认改掉屏幕上的大小，鼠标默认选字，编辑会另开图片编辑窗口，且只能点关闭、不能用 Command+W。

## 决定

- 截图像素留在静态画布上。Fabric 只画标注；拖动形状时只在上层画布预览，松手才生成对象。马赛克和模糊只在松手时对选区取样。
- 取色读已合成的像素，放大镜单独刷新，不带动整个编辑器重绘。
- 复制、保存、贴图和发送走原始像素。主进程只在真正写文件时编码，剪贴板用 `writeImage`，不再对同一张图做两次 PNG。
- 贴图默认按屏幕上的尺寸显示，且不能拖边改大小。设置里的「保持原尺寸」关闭后，恢复缩进窗口并可拖边。
- 贴图默认操作为拖动移动图片；点击工具条上的「选择文字」控件才进入选字模式（再点或按 Esc 恢复拖动）。
- 点编辑不打开新窗口，当前贴图窗口展开成编辑器；完成或 Esc 回到这张贴图。贴图创建、编辑返回或点击拖动时激活窗口焦点，支持 Command+W 关闭贴图窗口。

## 进度

实现已接入。`npm run build` 与 `npm run ui:shots` 通过，并查看了设置里的贴图开关、编辑器图片、取色放大镜和贴图三态。真实截图拖动、剪贴板、Command+W 和贴图内编辑还需在本机打包版手测。

## 验收

- 拖动箭头、直线、矩形、椭圆、画笔、高亮、遮挡、马赛克、模糊时界面跟手；松手后的形状与预览一致。
- 取色放大镜跟随指针，点一下才固定并复制颜色。
- 复制写入剪贴板，不再经过第二次 PNG 编码。
- 新贴图与截图在屏幕上的大小一致（超出工作区才缩小）。关闭「保持原尺寸」后缩进并可拖边。
- 默认拖动移动贴图，点击「选择文字」控件进入选字模式。编辑留在原窗口。Command+W 关闭贴图。
- `npm run build` 通过。界面改动用 `npm run ui:shots` 看设置、编辑器和贴图。真实截图、剪贴板和 Command+W 需在本机打包版里手测。
